# Smart TV лаунчер для Sony KDL-46HX753

Лёгкая веб-страница (HTML + CSS + JS без библиотек), которая открывается во встроенном браузере телевизора
(Opera). Ничего не устанавливается на сам ТВ: он просто открывает адрес страницы.

## Файлы

| Файл | Назначение |
|---|---|
| index.html | главный экран |
| style.css | оформление (без анимаций и flex) |
| apps.js | список приложений и поисковиков - редактируйте здесь |
| app.js | навигация с пульта, поиск, избранное |
| test.html | диагностика: проверка HTTPS, видео, localStorage, коды кнопок |

Все 5 файлов кладутся в ОДНУ папку на веб-сервере.

## Где разместить

Телевизор открывает страницу только по сетевому адресу, локальные файлы с USB браузер, скорее всего, не откроет
(не проверено). Варианты:

1. Бесплатный хостинг статических страниц (GitHub Pages, Cloudflare Pages и т.п.) - внешнее оборудование не нужно.
   Минус: такие сервисы работают только по HTTPS (TLS 1.2+). Если на ТВ HTTPS не работает (см. test.html),
   этот вариант не подойдёт.
2. Обычный хостинг, где страница доступна по http:// - подойдёт, если HTTPS на ТВ не работает.
3. Домашний веб-сервер (NAS, роутер с веб-сервером) по http://192.168.x.x/tv/.

## Запуск на телевизоре

1. HOME -> Applications -> Internet Browser.
2. OPTIONS -> URL entry -> введите адрес папки с файлами.
3. Добавьте страницу в закладки (меню OPTIONS браузера), чтобы открывать быстрее.

Сначала откройте `test.html`: он покажет, работает ли HTTPS и какие коды у кнопок пульта.

## Управление

Стрелки - перемещение, OK - открыть. В поле ввода OK запускает поиск/открытие.
"Править: вкл" - в этом режиме OK на плитке добавляет/убирает её из избранного.
"+ В избранное" добавляет сайт, адрес которого введён во втором поле.
Избранное хранится в localStorage браузера телевизора.

## Ограничения (проверьте на своём ТВ)

- Современные сайты (в т.ч. YouTube) могут не открыться: старый движок Opera и, возможно, старые версии TLS.
- Встроенное приложение YouTube на ТВ 2012 года Sony отключила в 2016 году.
- Flash и PDF встроенный браузер не поддерживает (по мануалу Sony).
- Коды кнопок Back и цветных кнопок не проверены: используйте test.html.
